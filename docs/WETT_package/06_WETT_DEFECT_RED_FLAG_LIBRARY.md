# WETT DEFECT & RED-FLAG LIBRARY

STATUS: COMPLETE  
PHASE: 6 — DEFECT & RED-FLAG LIBRARY  
BUSINESS: APOLLO / PHOENIX  
JURISDICTION: CANADA — STRICT ONTARIO / ALBERTA ROUTING  
LAST VERIFIED: 2026-09-22  
PURPOSE: Provide a field-focused, source-backed defect and red-flag library for common solid-fuel inspection findings, including what the inspector must verify, what evidence is required, when UTI applies, when escalation is warranted, and how to report the condition professionally.

> **Critical rule:** A defect name is not itself a compliance conclusion.  
> **Observed condition → governing source → applicable requirement → access level → evidence → status.**

> **Province isolation:**  
> **Ontario / APOLLO** findings use the Ontario knowledge layer and Ontario-referenced standards.  
> **Alberta / PHOENIX** findings use the Alberta knowledge layer and Alberta-referenced standards.  
> Never import an Ontario amendment into Alberta or an Alberta reference into Ontario.

> **Inspection-level lock:** If the item cannot be verified within the contracted SITE® level, use **Unable to Inspect (UTI)** or recommend a higher inspection level. Do not fill a visibility gap with assumption.

# Executive Summary

This Phase converts the most common solid-fuel inspection defects into a standardized field-response library.

Each defect entry answers:

- What was observed?
- Which system/component is involved?
- Which province applies?
- What must the inspector check next?
- What source controls the requirement?
- What measurements are needed?
- What photographs/evidence are needed?
- Is the finding:
  - Compliant,
  - Not Compliant,
  - Not Applicable,
  - Unable to Inspect,
  - or still pending manufacturer/case-specific verification?
- When should the inspection escalate?
- What professional report wording should be used?
- What corrective action is appropriate?

The library deliberately avoids common bad practices such as:

- calling every crown crack a WETT failure;
- treating every rust spot as unsafe;
- claiming a hidden liner is compliant because the exterior chimney looks good;
- declaring “annual sweeping is legally required” when the current Fire Code instead requires periodic inspection and cleaning as often as necessary;
- using another manufacturer’s installation manual because the appliance “looks similar”;
- using Ontario requirements in Alberta;
- using Alberta requirements in Ontario.

WETT’s current SITE® material supports the basic logic behind this library: inspections identify visible deficiencies/red flags, inaccessible items may be UTI, and observed concerns can justify Technical or Invasive inspection. WETT also specifically identifies smoke spillage and rapid creosote accumulation as conditions warranting discontinuation of use and qualified evaluation.

# Core Defect Classification Logic

For every defect:

## 1. Confirm Province

```text
APOLLO → Ontario
PHOENIX → Alberta
```

## 2. Confirm System

Examples:
- masonry fireplace;
- wood stove;
- fireplace insert;
- masonry chimney;
- factory-built chimney;
- factory-built fireplace.

## 3. Confirm SITE® Level

- Visual
- Technical
- Invasive

## 4. Record the Observation

No interpretation yet.

Example:

> “Approximately 4 mm open crack observed across the exterior crown surface extending from the flue-liner area toward the north edge.”

Not:

> “Crown failed WETT.”

## 5. Select Governing Source

Possible authorities:

- WETT procedure;
- Ontario Building Code;
- Ontario Fire Code;
- NBC(AE);
- NFC(AE);
- CSA B365-17;
- applicable ULC standard;
- manufacturer instructions;
- municipal requirement;
- industry best practice.

## 6. Measure / Photograph

Collect evidence necessary to make the conclusion.

## 7. Assign Status

Only:

- **Compliant**
- **Not Compliant**
- **Not Applicable**
- **Unable to Inspect (UTI)**

Where a source cannot yet be established:

- **MANUFACTURER LOOKUP REQUIRED**
- **CASE-SPECIFIC DETERMINATION REQUIRED**
- **NOT VERIFIED**

These are workflow controls, not replacement WETT status labels.

# Defect 1 — Cracked Chimney Crown / Cap

**Province:** Ontario / Alberta — use province-specific code layer  
**System:** Masonry / concrete chimney  
**Typical Inspection Level:** Visual; Technical if roof access is required  
**Classification:** CODE REQUIREMENT + MAINTENANCE / CONDITION

## What Was Observed

Examples:
- hairline surface crack;
- open crack;
- radial crack from liner;
- full-depth-looking crack;
- spalled crown;
- separated crown section;
- failed patch.

## What Must Be Checked

- actual crown/cap type;
- crack width and length;
- water entry evidence;
- slope away from flue;
- drip projection;
- crown overhang;
- liner/crown interface;
- freeze-thaw deterioration;
- loose material;
- whether reinforcing/construction can be established;
- whether movement/structural displacement is present.

## Relevant Requirement

Both Ontario and Alberta current Part 9 layers contain chimney-cap/crown requirements in **9.21.4.6**, including weather-shedding construction, slope and drip detailing.

The currently verified common measurable element is a drip projection of at least **25 mm from the chimney wall** for the applicable cap construction.

## Measurements Needed

- crack width where material;
- crown projection/drip;
- visible slope/drainage condition;
- displacement if present.

## Photo Requirements

- full crown from context;
- crack overview;
- close-up with scale;
- drip/edge;
- liner/crown interface;
- water staining if present.

## Possible Classification

### Not automatically Not Compliant
A small superficial crack alone does not justify an unsupported whole-system failure.

### Not Compliant
Appropriate where the actual cap/crown construction or deterioration fails the applicable requirement.

### UTI
If crown cannot be observed adequately from the contracted inspection level.

## Escalation Trigger

- major displacement;
- loose concrete/masonry;
- structural movement;
- crack extends into chimney body;
- significant water penetration;
- suspected freeze-thaw structural loss.

## Recommended Report Wording

> Cracking was observed in the masonry chimney crown/cap. The crown should be evaluated against the applicable provincial chimney-cap requirements, including weather-shedding, slope and drip detailing. The observed crack can permit water entry and accelerate freeze-thaw deterioration. Repair is recommended where the crack compromises the required cap function.

## Recommended Action

- repair/seal if minor and technically suitable;
- rebuild crown where deterioration/configuration is substantial;
- qualified masonry evaluation for structural concerns.

## Source Route

Ontario:
- OBC 9.21.4.6
- Ontario knowledge layer

Alberta:
- NBC(AE) 9.21.4.6
- Alberta knowledge layer

**Last Verified:** 2026-09-22  
**Verification Status:** VERIFIED

# Defect 2 — Missing or Severely Damaged Chimney Crown / Cap

**Province:** Ontario / Alberta  
**System:** Masonry chimney  
**Inspection Level:** Visual / Technical  
**Classification:** CODE REQUIREMENT

## What Was Observed

- no discernible crown/cap;
- exposed chimney-wall core;
- broken/missing sections;
- failed flat mortar wash;
- crown so deteriorated it no longer sheds water.

## What Must Be Checked

- whether a code-compliant cap/crown exists;
- top masonry protection;
- liner projection;
- water entry;
- chimney-wall deterioration;
- temporary coverings;
- flue termination device vs actual masonry cap/crown.

## Important Distinction

A metal rain cap on the flue is not the same thing as the masonry chimney cap/crown.

## Measurements Needed

- crown/drip projection if present;
- liner projection if accessible;
- extent of missing cap.

## Photos

- entire chimney top;
- top masonry;
- liner;
- damaged/missing area.

## Status

Where the required cap/crown construction is absent or materially failed:
**Not Compliant**

## Escalation

- masonry instability;
- exposed/loose units;
- extensive water damage.

## Report Wording

> The masonry chimney does not have an intact weather-shedding crown/cap at the inspected area. The applicable provincial building-code provisions require a chimney cap/crown configured to protect the chimney and shed water. Repair/reconstruction by a qualified masonry/chimney professional is recommended.

## Source

OBC / NBC(AE) 9.21.4.6

**Last Verified:** 2026-09-22  
**Verification Status:** VERIFIED

# Defect 3 — Missing / Insufficient Drip Detail Where Applicable

**Province:** Ontario / Alberta  
**System:** Masonry chimney crown/cap  
**Inspection Level:** Visual / Technical  
**Classification:** CODE REQUIREMENT

## Observation

- crown flush with chimney wall;
- no visible drip projection;
- drip projection appears below required dimension;
- water tracks directly down chimney face.

## Requirement

The current Ontario and Alberta chimney-cap provisions include a drip extending at least **25 mm from the chimney wall** for the applicable construction.

## What Must Be Checked

- true crown edge vs parging/coating;
- measurement from chimney wall;
- all sides where accessible;
- whether cap type falls under the provision;
- water staining/deterioration.

## Measurement

- crown drip projection.

## Photos

- ruler/tape at edge;
- context;
- water staining.

## Status

If the applicable current requirement controls and measurement is below requirement:
**Not Compliant**

For historical installations:
**CASE-SPECIFIC DETERMINATION REQUIRED** before asserting retroactive original-installation non-compliance.

## Report Wording

> The inspected crown/cap drip projection measured approximately [x] mm. The applicable current provincial chimney-cap provision specifies a minimum 25 mm drip projection for this cap configuration. Historical-code applicability should be considered where the original installation predates the current code.

## Source

OBC / NBC(AE) 9.21.4.6

**Last Verified:** 2026-09-22  
**Verification Status:** VERIFIED

# Defect 4 — Cracked / Damaged Chimney Liner

**Province:** Ontario / Alberta  
**System:** Masonry chimney / fireplace flue  
**Inspection Level:** Visual where visible; often Technical / Invasive  
**Classification:** CODE / FIRE CODE CONDITION + POTENTIAL RED FLAG

## Observation

- cracked clay tile;
- displaced liner;
- missing liner section;
- open liner joint;
- spalled liner;
- heat damage;
- fractured liner after chimney fire.

## What Must Be Checked

- liner type;
- full visible extent;
- location;
- crack severity;
- offset/displacement;
- previous chimney-fire history;
- soot/creosote;
- evidence of heat transfer/leakage;
- whether flue scan is appropriate;
- whether repair/relining is required.

## Relevant Requirement

Both province building-code layers contain chimney-liner requirements.

Current Fire Codes also require repair/replacement of structural deficiency/decay or dangerous chimney/flue conditions.

Ontario Fire Code 2.6.1.4 specifically requires repair/replacement for structural deficiency or decay.

Alberta NFC(AE) 2.6.1.4 similarly addresses structural deficiency/decay.

## Measurement

Usually:
- location/depth;
- visible crack width;
- flue dimension;
- liner dimensions.

## Photos

- liner crack;
- context;
- video-scan image if used;
- top/bottom liner condition.

## Status

If damage is verified and compromises required liner integrity:
**Not Compliant**

If only a small portion is visible and the full condition matters:
- document observed defect;
- remaining liner can still be **UTI**.

## Escalation

- suspected chimney fire;
- multiple cracked tiles;
- displaced liner;
- missing sections;
- concealed extent unknown.

Recommend:
**Technical / Invasive / video-scan evaluation as appropriate.**

## Report Wording

> Damage was observed in the accessible chimney liner at [location]. The liner condition requires further evaluation because cracking/displacement can compromise the flue’s ability to contain combustion products and heat. The remaining concealed liner was not fully evaluated within the present inspection scope.

## Source

- provincial Section 9.21
- applicable Fire Code
- WETT SITE® escalation principle

**Last Verified:** 2026-09-22  
**Verification Status:** VERIFIED

# Defect 5 — Missing Chimney Liner

**Province:** Ontario / Alberta  
**System:** Masonry chimney  
**Inspection Level:** Visual / Technical  
**Classification:** POTENTIAL CODE / FIRE CODE DEFICIENCY — CONFIGURATION AND HISTORICAL APPLICATION MATTER

## Observation

- masonry flue appears unlined;
- no liner visible at top/bottom;
- exposed masonry within flue.

## What Must Be Checked

- appliance type;
- chimney construction;
- original installation date;
- alterations;
- current applicable code;
- historical code if original legality matters;
- whether liner may exist but is not visible;
- permit/documentation;
- previous chimney fire.

## Critical Rule

Do not state “missing liner” solely because the liner was not visible from one inspection point.

If liner existence cannot be established:
**UTI / TECHNICAL LOOKUP**

## Fire Code Significance

Historical Ontario Fire Code language explicitly used absence of a liner as an example of structural deficiency. The current code retains the broader requirement to eliminate structural deficiency/decay.

## Status

If no required liner exists and applicability is established:
**Not Compliant**

If existence cannot be determined:
**UTI**

## Report Wording

> No chimney liner could be confirmed within the areas accessible during this inspection. Because the liner condition/existence is material to the system evaluation, no compliance conclusion is made for the concealed flue. Further inspection and/or documentation is required.

## Source

- provincial Section 9.21
- Fire Code 2.6.1.4
- historical code lookup when necessary

**Last Verified:** 2026-09-22  
**Verification Status:** VERIFIED WORKFLOW / HISTORICAL APPLICATION CASE-SPECIFIC

# Defect 6 — Damaged Firebrick / Firebox Lining

**Province:** Ontario / Alberta  
**System:** Masonry fireplace / wood stove / factory-built fireplace  
**Inspection Level:** Visual  
**Classification:** CODE / MANUFACTURER / CONDITION DEPENDING ON SYSTEM

## Observation

- hairline crack;
- open crack;
- missing brick;
- spalling;
- loose brick;
- eroded mortar joint;
- exposed backing;
- broken factory-built refractory panel.

## What Must Be Checked

### Masonry fireplace
- firebox lining requirements;
- depth/severity;
- open path to masonry/combustible construction;
- missing unit;
- structural significance.

### Listed appliance / factory-built fireplace
- manufacturer replacement criteria;
- refractory-panel service limits;
- approved part.

## Critical Rule

Not every refractory/firebrick crack is automatically a code failure.

Factory-built systems especially require:
**MANUFACTURER LOOKUP REQUIRED**

## Photos

- whole firebox;
- defect close-up;
- scale reference;
- exposed material behind defect.

## Status

- cosmetic/serviceable crack → may be recommendation only;
- missing/severely failed lining compromising required protection → **Not Compliant / repair required**;
- manufacturer threshold unknown → **MANUFACTURER LOOKUP REQUIRED**.

## Report Wording

> [Cracking/spalling/missing material] was observed in the [firebrick/refractory] at [location]. The technical significance depends on the system construction and, for listed appliances, the manufacturer’s service criteria. Repair or replacement is recommended where the defect compromises the required firebox lining.

# Defect 7 — Rust / Corrosion

**Province:** Ontario / Alberta  
**System:** Flue pipe / factory-built chimney / insert / fireplace / flashing / cap  
**Inspection Level:** Visual / Technical  
**Classification:** CONDITION / MANUFACTURER / FIRE CODE WHEN STRUCTURAL DECAY EXISTS

## Observation

- surface rust;
- advanced corrosion;
- perforation;
- scale/flaking;
- rust at joints;
- corrosion around flashing/storm collar;
- corroded prefab chimney.

Ottawa Fire Services identifies corroded flashing and corroded prefabricated chimneys among common chimney problems.

## What Must Be Checked

- component identity;
- material;
- depth;
- perforation;
- structural strength;
- joint integrity;
- moisture source;
- manufacturer rejection criteria;
- heat damage vs normal oxidation.

## Status

Surface discoloration alone:
not automatically Not Compliant.

Advanced corrosion compromising component integrity:
**Not Compliant / replace or repair as applicable.**

## Escalation

- perforation;
- structural loss;
- inner-wall damage;
- unknown concealed corrosion;
- factory-built chimney fire history.

## Report Wording

> Corrosion was observed on the [component]. The affected area should be evaluated for material loss and structural/venting integrity. Surface oxidation alone does not establish failure; however, advanced corrosion, perforation, or loss of component integrity requires corrective action.

## Sources

- Fire Code dangerous-condition/decay requirements
- manufacturer
- Ottawa Fire Services guidance

**Last Verified:** 2026-09-22  
**Verification Status:** VERIFIED

- connector close to drywall/wood framing;

## What Must Be Checked

- connector type;
- single-wall vs listed double-wall;

- measurement reference points.

## Measurements

- shortest controlling clearance;
- shield air gap/coverage where applicable.

## Photos

- full route;
- measurement;

## Status

If measured clearance is below applicable requirement:
**Not Compliant**

## Escalation

- concealed wall/ceiling penetration;
- overheating;
- charring;
- unknown listed connector system.

## Report Wording

> The measured clearance between the flue pipe/connector and the nearest combustible material was approximately [x]. The applicable [B365/manufacturer] requirement for this connector configuration is [requirement]. The observed clearance does not meet the verified requirement.

## Source

- CSA B365-17 in both province layers
- manufacturer instructions

# Defect 15 — Combustible Material Contact / Clearance Intrusion

**Province:** Ontario / Alberta  
**System:** Appliance / connector / masonry chimney / factory-built chimney / fireplace  
**Inspection Level:** Visual / Technical  
**Classification:** CODE / FIRE CODE / MANUFACTURER

## Observation

- wood framing touching chimney;
- spray foam in clearance space;
- insulation against factory-built chimney;
- mantel/trim too close;
- stored firewood in required clearance;
- combustible finish touching connector.

## Fire Code Significance

Alberta NFC(AE) 2.6.1.5 explicitly requires required clearances around chimneys, flue pipes and appliances to be maintained and prohibits combustible materials within the required clearance space.

Ontario Fire Code and Building Code similarly require maintenance of safe system conditions and applicable installation clearances.

## What Must Be Checked

- which component;
- actual required clearance;
- combustible material;
- manufacturer;
- historical installation;
- signs of heat/charring.

## Measurement

Shortest clearance.

## Photos

- contact;
- context;
- measurement;
- charring.

## Status

If required clearance is not maintained:
**Not Compliant**

## Escalation

- charred framing;
- concealed contact;
- insulation packed around factory-built chimney;
- suspected pyrolysis/fire damage.

## Report Wording

> Combustible material was observed within the required clearance space at [location]. The measured clearance was approximately [x] compared with the applicable requirement of [requirement]. Correction is required to restore the specified clearance.

# Defect 16 — Creosote / Combustible Deposit Buildup

**Province:** Ontario / Alberta  
**System:** Chimney / liner / flue pipe / appliance  
**Inspection Level:** Visual / Technical  
**Classification:** FIRE CODE MAINTENANCE / WETT RED FLAG

## Observation

- soot;
- flaky deposit;
- glazed creosote;
- heavy accumulation;
- rapid recurring buildup.

WETT identifies rapid creosote accumulation as a concern that should lead the user to discontinue use and contact a WETT-certified technician or sweep.

Ontario and Alberta Fire Codes require cleaning as often as necessary to keep chimneys/flues/flue pipes free from dangerous combustible-deposit accumulation.

## What Must Be Checked

- type/appearance;
- location;
- extent accessible;
- last cleaning;
- fuel/moisture/use pattern;
- draft issues;
- smoke spillage;
- chimney temperature;
- appliance operation;
- chimney-fire evidence.

## Status

Dangerous accumulation:
**Not Compliant / cleaning required**

If full extent not visible:
remaining area may be **UTI**.

## Escalation

- glazed creosote;
- suspected chimney fire;
- rapid recurrence;
- blocked flue;
- smoke spillage.

## Report Wording

> Combustible deposits were observed in the accessible portion of the venting system. The applicable Fire Code requires cleaning as often as necessary to prevent dangerous accumulations. Cleaning and investigation of contributing operating/draft conditions are recommended before continued use.

## Important

Do not write:
> “The law requires one sweep every year.”

# Defect 17 — Suspected Previous Chimney Fire

**Province:** Ontario / Alberta  
**System:** Chimney / liner / connector  
**Inspection Level:** Visual → commonly Technical/Invasive escalation  
**Classification:** HIGH-PRIORITY RED FLAG

## Indicators

Possible indicators include:
- warped metal;
- discoloured chimney components;
- cracked/displaced liner;
- glazed/puffy deposits;
- owner/fire-department report;
- damaged cap;
- heat-damaged support/component.

Do not declare a chimney fire from one ambiguous visual clue.

## Fire Code

Both Ontario and Alberta current Fire Codes require inspection **after any chimney fire**.

## What Must Be Checked

- client history;
- fire department records if available;
- liner;
- factory-built chimney sections;
- connector;
- supports;
- attic/chase;
- termination;
- combustible clearances;
- fire damage.

## Status

Chimney-fire history is not itself the final status.

Affected components require evaluation.

## Escalation

Strongly consider:
- Technical inspection;
- Invasive inspection;
- video scan;
- manufacturer review;
- replacement where listed system is heat-damaged.

## Report Wording

> Conditions/history are consistent with a possible prior chimney-fire event. The present inspection level is not sufficient to establish the full extent of concealed damage. A more detailed chimney evaluation is recommended before continued use.

**Verification Status:** VERIFIED

# Exceptions / Edge Cases

## 1. Defect is obvious but source is not available

Do not invent clause.

Use:
**NOT VERIFIED**

and record the observed condition separately.

---

## 2. Defect appears worse than code issue

Example:
massive leaning chimney.

The inspector can document the condition and recommend specialist evaluation without pretending to perform structural engineering.

---

## 3. Customer repaired defect immediately

The report should distinguish:
- original observed condition;
- repair performed;
- whether repair was actually inspected;
- whether a new/reinspection result is justified.

Do not erase the original observation.

---

## 4. Photo does not prove measurement

Do not claim exact clearance from visual estimate.

Measure it.

---

## 5. Code requirement is newer than installation

Do not automatically label historic construction Not Compliant under the newest code.

Check:
- installation date;
- alteration;
- Fire Code current condition;
- historic code.

---

## 6. Defect is hidden behind insert

Use UTI at Visual level.

Do not assume:
> “Insert was installed professionally, so connection is good.”

---

## 7. Manufacturer no longer exists

Search:
- archived manual;
- test lab/certification;
- AHJ records;
- permit;
- product documentation.

If unresolved:
**NOT VERIFIED**
