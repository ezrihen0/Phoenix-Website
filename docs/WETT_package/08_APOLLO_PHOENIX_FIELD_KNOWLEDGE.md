# Evidence Integrity Rules

## 1. No photo = do not invent photo content

If a prior case record says photos existed but the exact images are not currently attached to the case file:

```text
Photo: EXISTED — NOT CURRENTLY LINKED
```

Do not describe image details that are not preserved.

---

## 2. No measurement = write exactly that

```text
Measurement: NOT PRESERVED IN AVAILABLE CASE RECORD
```

Do not infer a measurement from a photograph, memory, or typical code value.

---

## 3. No final classification = keep case open

Use:

```text
Final Classification:
NOT VERIFIED / CASE RECORD INCOMPLETE
```

A real field observation is still useful even when the final disposition was not preserved.

---

## 4. A customer saying “passed” is not enough

A field case should preserve the actual inspection classification or report outcome where available.

Do not convert informal customer language into:
- Compliant,
- Not Compliant,
- UTI,
- N/A

unless the inspection record supports it.

## Finding

Phoenix completed broader property inspections including roof/chimney areas.

Two units — **11 and 24** — were inaccessible internally and were initially excluded from completed reports.

Those units shared chimney infrastructure with other units whose chimney/roof portions had already been inspected.

The internal unit inspection was still outstanding.

## Measurement

**NOT PRESERVED IN AVAILABLE CASE RECORD**

## What Inspector Noticed

This is a strong real-world example of why:

**Shared chimney inspected ≠ individual unit fully inspected**

The visible/shared chimney condition does not substitute for:

- appliance;
- connection;
- hearth;
- clearances;
- interior components;
- unit-specific findings.

## Applicable Requirement

**Source classification:** WETT PROCEDURE

Use:
- SITE® access limitations;
- UTI principles;
- written-report scope;
- Alberta system requirements only after the relevant component is actually inspected.

## Final Classification — Initial Visit

For the inaccessible interior portions:

**UNABLE TO INSPECT (UTI) / INSPECTION INCOMPLETE**

No full unit conclusion should be issued from roof/shared-chimney evidence alone.

## Final Classification — Follow-Up

Return access was obtained and the outstanding inspections were later completed.

The detailed final technical classifications are **not preserved** in this Phase 8 source record.

## Repair Recommendation

No repair recommendation should be created solely from lack of access.

Correct action:

**RETURN VISIT / OBTAIN ACCESS**

## Final Report Wording — Initial Visit

> **Unable to Inspect (UTI):** Interior appliance and connection components for Unit [11/24] were not accessible at the time of inspection. Although shared exterior chimney/roof components were inspected, no compliance conclusion is made for the inaccessible unit-specific system components.

## Source

- FIELD EXPERIENCE — Phoenix / Okotoks April 2026 inspection program
