# Executive Summary

Alberta’s current building-code framework is the **National Building Code – 2023 Alberta Edition (NBC(AE)), 2nd printing**, published August 17, 2026. The first printing came into force May 1, 2024 and succeeded the National Building Code – 2019 Alberta Edition.

Alberta’s current fire-code framework is the **National Fire Code – 2023 Alberta Edition (NFC(AE)), 2nd printing**, also published August 17, 2026.

The NBC(AE) 2023 references **CSA B365-17** for the installation of solid-fuel-burning appliances and equipment. For the typical residential systems relevant to Phoenix, the current code reference table also identifies:

- **CAN/ULC-S610:2018** — Factory-Built Fireplace Systems.
- **ULC-S628-93** — Standard for Fireplace Inserts.
- **CAN/ULC-S629:2016** — 650°C Factory-Built Chimneys.
- **CAN/ULC-S639-M87** — Steel Liner Assemblies for Solid-Fuel Burning Masonry Fireplaces.

These editions are Alberta-specific legal-reference data and must not be replaced with Ontario’s referenced editions or with the newest commercial edition of a standard simply because a newer edition exists.

The NBC(AE) residential provisions relevant to Phoenix are concentrated in:

- **Section 9.21 — Masonry and Concrete Chimneys and Flues**
- **Section 9.22 — Fireplaces**
- **Section 9.33 — Heating and Air-conditioning**
- **CSA B365-17** for solid-fuel appliance installation
- the applicable ULC product standard and manufacturer instructions.

The current Alberta Fire Code creates significant ongoing duties. Every chimney, flue and flue pipe must be inspected to identify dangerous conditions:

- at intervals not greater than **12 months**;
- when an appliance is added; and
- after a chimney fire.

The same provision requires cleaning **as often as necessary** to keep the system free from dangerous accumulations of combustible deposits. This is not the same as a universal law requiring a sweep once every 12 months.

A critical Alberta/other-jurisdiction isolation point is combustion air. The current Alberta fireplace provision does **not** state that every fireplace must have an outdoor-combustion-air supply. It provides requirements **where a supply of combustion air is provided directly to the fire chamber**. Therefore, an Ontario-specific universal outdoor-air requirement must not be imported into Phoenix inspections.

Calgary and Edmonton primarily add **permit, application, inspection, and enforcement processes**, not a replacement technical chimney/fireplace code:

- Calgary identifies wood-burning fireplaces and stoves as building-permit work and requires permits for fireplace projects.
- Edmonton treats solid-fuel appliance installation as a Home Improvement Permit matter and provides a dedicated **Interior Solid Fuel Appliance Final Building Inspection** process.

# Source-Control Note — 2nd Printing vs Detailed Clause Text

Alberta’s official code pages identify the **2nd printings published August 17, 2026** as current.

The publicly indexed NRC detailed clause text used for many Part 9 and Part 2 clause-level checks in this research is the 2023 Alberta Edition first-printing text. Alberta states that the second printing incorporates revisions and errata.

During this phase:

- the current 2nd-printing status was verified from Alberta Municipal Affairs;
- available Alberta STANDATA/errata and current indexed material were searched for chimney/fireplace-specific changes;
- no material change to the Phase 4 chimney/fireplace provisions below was identified.

For a legal dispute, enforcement proceeding, or unusual edge case, verify the exact wording in the current 2nd printing before quoting a clause verbatim.

This does **not** prevent the knowledge layer from being operational because the governing code family, source locations, standards, inspection significance, and current adoption framework are established.

# 4. Transition to NBC(AE) 2023

Alberta’s April 2024 transition notice confirms the new 2023 Alberta building/fire codes came into force May 1, 2024 and provides transition mechanisms for work already in progress or sufficiently advanced under the previous code.

- an existing valid permit;
- permit application timing;
- substantially complete plans/specifications;
- authority-having-jurisdiction acceptance;

# 5. Existing Installations

The current NBC(AE) governs new construction and applicable alteration/change-of-use work.

An untouched older installation is not automatically judged as though it were installed yesterday.

At the same time, the current NFC(AE) contains ongoing inspection, maintenance, cleaning, clearance and hazardous-condition duties.

### Operational separation

For an existing system distinguish:

**A. Original installation legality**
- historical code edition;
- permit;
- listing;
- manufacturer requirement at time of installation.

**B. Current alteration**
- current permit/code may apply to altered work.

**C. Current condition**
- current Fire Code duties can apply to dangerous conditions, deposits, required clearances and maintenance.
