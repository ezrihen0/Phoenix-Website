# WETT SYSTEM-BY-SYSTEM INSPECTION LIBRARY

STATUS: COMPLETE  
PHASE: 5 — SYSTEM-BY-SYSTEM INSPECTION LIBRARY  
BUSINESS: APOLLO / PHOENIX  
JURISDICTION: CANADA — WITH STRICT ONTARIO / ALBERTA ROUTING  
LAST VERIFIED: 2026-09-22  
PURPOSE: Convert the verified WETT Core, CSA B365 knowledge map, Ontario layer, and Alberta layer into practical field inspection workflows from arrival through final report for the common solid-fuel systems handled by Apollo and Phoenix.

> **Primary operating rule:** This file is a field workflow, not an independent code. Every compliance conclusion must still point to the correct governing source for the province, appliance, chimney system, installation date, and inspection level.

> **Province isolation:**  
> **APOLLO = Ontario** → WETT Core + Ontario layer + Ontario-referenced standards + manufacturer.  
> **PHOENIX = Alberta** → WETT Core + Alberta layer + Alberta-referenced standards + manufacturer.  
> Never silently move a provincial requirement across the border.

> **Inspection-level lock:** A checklist item does not authorize access beyond the contracted SITE® inspection level. If the condition cannot be evaluated within the agreed access level, use **Unable to Inspect (UTI)** or recommend a higher inspection level.

# Executive Summary

This document turns the technical knowledge pack into four repeatable inspection paths:

1. **Wood Stove**
2. **Fireplace Insert / Hearth-Mounted Stove**
3. **Masonry Fireplace**
4. **Factory-Built Fireplace**

Each path is designed to answer the same operational questions:

- What must be identified before a compliance judgment is made?
- What must be observed?
- What must be measured?
- What must be photographed?
- Which authority controls the item?
- What is accessible at Visual, Technical, or Invasive level?
- When should the inspector use UTI?
- When is manufacturer documentation mandatory?
- When should the inspection escalate?
- How should the final report be structured?

The workflow intentionally separates:

- **WETT inspection procedure**
- **building/fire code**
- **CSA/ULC referenced standards**
- **manufacturer requirements**
- **municipal permit/process**
- **industry best practice**
- **Apollo/Phoenix field experience**

A field inspector should never have to jump directly from “I see something unusual” to “pass/fail.”

The correct sequence is:

**Observation  
→ System / component  
→ Province  
→ Inspection level  
→ Applicable authority  
→ Measurement / evidence  
→ Compliant / Not Compliant / N/A / UTI  
→ Recommendation / escalation  
→ Final report**

# STEP 1 — Confirm SITE® Inspection Level

## Visual — Readily Accessible

Typical allowed scope:
- visible appliance/system components;
- clearance measurements;
- ground-accessible doors/dampers/cleanouts;
- chimney inspection from ground;
- easily visible flue portions;
- basic tools.

Do not treat:
- concealed framing;
- inaccessible liner;
- hidden chase;
- closed attic;
- inaccessible roof;
- internal chimney construction

as inspected when access was not obtained.

## Technical — Accessible

May include:
- ladders;
- roof access;
- attic access;
- removal of panels/doors;
- flue-pipe disassembly;
- cleanout access;
- hand tools.

## Invasive — Concealed Accessibility

May include:
- opening walls/ceilings;
- invasive chimney work;
- specialty equipment;
- destructive access;
- written client agreement;
- AHJ/permit implications where structural elements are compromised.

---

# STEP 2 — Safety / Conditions Before Inspection

Before beginning:

- Appliance is not actively burning.
- Components are cool enough for safe inspection.
- Inspector has safe access.
- Roof/ladder conditions are acceptable if roof access is within scope.
- No immediate hazard requires the inspection to stop.
- Known chimney fire, smoke spillage, structural movement, or severe damage is recorded before ordinary checklist work continues.

If an immediate hazard is observed:

1. Record the condition.
2. Photograph it.
3. Do not create unsupported certainty about concealed damage.
4. Recommend discontinuation of use where justified by the actual hazard.
5. Escalate the inspection or specialist evaluation as appropriate.

Each applicable item should resolve to one of:

- **Compliant**
- **Not Compliant**
- **Not Applicable**
- **Unable to Inspect (UTI)**

Do not create a fifth category such as “probably okay.”

Use notes/recommendations for uncertainty while preserving the WETT status framework.

WETT material confirms that inspections use written forms and photographs are part of inspection documentation; however, the exact current mandatory WETT Inspection SOP photograph schedule remains unresolved from Phase 1.

Therefore this Phase defines an **internal evidence set**, not the official WETT mandatory photo list.

For every system, evidence should normally include:

1. Wide system overview.
2. Appliance/fireplace opening.
3. Certification/data label when present.
4. Flue-pipe / vent path.
5. Chimney exterior.
6. Termination.
7. Hearth/floor protection.
8. Critical combustible clearances.
9. Each material deficiency.
10. Any condition causing UTI when photographable.
11. Manufacturer/chimney-system labels when available.
12. Crown/cap/flashing for masonry chimney where applicable.

**Do not label this list “WETT mandatory photos.”**

# 3.3 Hearth / Floor Protection

Inspect:

- noncombustible protection present;
- front extension;
- side/rear extension where applicable;
- continuity;
- joints/gaps;
- floor beneath/adjacent;
- appliance legs/pedestal configuration;
- thermal vs ember protection requirement;
- R-value/product assembly if manufacturer requires thermal protection.

### Authority

First:
- manufacturer manual/listing.

Then:
- applicable B365 provision.

Do not assume:
- tile = adequate thermal protection;
- metal sheet = adequate protection;
- a large pad = compliant without correct dimensions/performance.

### Measurements

Record:
- front extension;
- side extension;
- relevant rear extension;
- pad height/thickness only where technically relevant;
- raised appliance condition.

### Photos

- entire hearth.
- tape measure at critical front dimension.
- side dimension.
- edge/layer/product label where accessible.

### Report outcome

- Compliant
- Not Compliant
- UTI if required performance/construction cannot be established and evidence is unavailable.

# 3.4 Walls / Appliance Clearances

Identify all nearby combustible surfaces:

- drywall over wood framing;
- wood panel;
- trim;
- shelves;
- furniture if relevant to use;
- corner framing;
- ceiling;
- alcove.

Record:

- side clearance;
- rear clearance;
- corner clearance;
- ceiling/alcove clearance where applicable.

### Rule

Use:
**manufacturer certified clearance first where applicable**

Do not replace a listed appliance clearance with a generic number simply because a generic code value exists.

### Shielding

If clearance reduction is claimed:

Inspect:
- shield material;
- spacer/air gap;
- ventilation;
- top/bottom openings;
- coverage;
- mounting;
- manufacturer-approved shield if required.

A noncombustible board attached directly to a combustible wall is not automatically a valid clearance-reduction system.

### Photos

- tape measure at each controlling clearance.
- shield front.
- shield air gap/edge.
- combustible surface.

# 3.11 Fire Code / Ongoing Maintenance

Both Ontario and Alberta currently contain requirements for chimney/flue/flue-pipe inspection at intervals not exceeding 12 months, when an appliance is added, and after chimney fire, with cleaning as often as necessary to control combustible deposits.

### Inspector asks

- Last inspection?
- Last sweep?
- Any chimney fire?
- Any rapid creosote?
- Any smoke spillage?
- Any appliance added?

### Important

Do not report:
> “The law requires an annual sweep.”

Report the actual inspection/cleaning duty accurately.

# SYSTEM 2 — FIREPLACE INSERT / HEARTH-MOUNTED STOVE

# 4. System Definition

A listed solid-fuel insert or hearth-mounted appliance installed into an existing:

- masonry fireplace; or
- factory-built fireplace where specifically listed/permitted.

This system must be treated as a combination of:

1. **insert appliance**
2. **original fireplace**
3. **liner / chimney connection**
4. **existing chimney**
5. **hearth / facing / surround**

Do not inspect only the insert face and ignore the original fireplace/chimney.

# SYSTEM 3 — MASONRY FIREPLACE

# 7. System Definition

A site-built masonry fireplace and associated masonry/concrete chimney.

This system is different from a factory-built fireplace.

CSA B365 does not replace the building-code construction requirements for a site-built masonry fireplace.

Primary technical construction authority is the applicable provincial building code.

---

# 8. Governing Authority — Masonry Fireplace

## Ontario / Apollo

Use:

- WETT Core.
- Ontario Building Code Sections 9.21 / 9.22.
- Ontario Fire Code.
- manufacturer/listing only for installed listed components/accessories.
- Ottawa process where material.

## Alberta / Phoenix

Use:

- WETT Core.
- NBC(AE) Sections 9.21 / 9.22.
- NFC(AE).
- manufacturer/listing for installed components.
- Calgary/Edmonton process where material.

### Important Province Difference

Ontario and Alberta must not be assumed identical.

Example already established in prior phases:
- Ontario’s current fireplace outdoor-combustion-air amendment is materially different from Alberta’s wording.

---

# 9. Masonry Fireplace — Arrival Sequence

# 9.1 Confirm It Is Site-Built Masonry

Look for:

- masonry firebox;
- masonry chimney;
- brick/firebrick;
- masonry smoke chamber;
- damper;
- no factory-built fireplace data plate.

If identity is uncertain:
**NOT VERIFIED**

Do not classify a zero-clearance factory-built box with brick facing as a masonry fireplace.

---

# 9.2 Firebox

Inspect visible:

- firebrick;
- mortar joints;
- cracks;
- spalling;
- missing brick;
- open joints;
- burn-through;
- combustible intrusion;
- severe distortion if metal liner/components exist;
- evidence of modification.

### Photos

- full firebox.
- rear wall.
- left/right walls.
- floor.
- major cracks/open joints.

### Classification

Do not call every hairline refractory crack a code violation.

Determine:
- construction defect;
- maintenance issue;
- structural defect;
- fire path;
- manufacturer requirement if listed liner/components exist.

---

# 9.3 Hearth

Inspect:

- noncombustible material;
- front extension;
- side extension;
- cracks/gaps;
- combustible floor exposure;
- settlement;
- loose tile/stone;
- raised firebox condition;
- support if observable.

### Common current Part 9 baseline

Both current Ontario and Alberta layers include a typical masonry fireplace hearth dimension of:
- **400 mm in front**
- **200 mm beyond each side**

for the applicable code condition.

### Critical historical caution

Do not automatically impose current new-construction values retroactively on every historic fireplace without determining applicable code/alteration status.

### Photo
- full hearth.
- front measurement.
- side measurement.
- cracks/gaps.

- liner interface;
- seal;
- vegetation;
- freeze-thaw damage;
- failed coating/patch.

### Verified common current Part 9 item

Both Ontario and Alberta current layers include a **25 mm** drip projection requirement for the applicable masonry chimney-cap construction.

### Reporting rule

A crack must be described by:
- width/severity where useful;
- location;
- drainage impact;
- water entry;
- code significance.

Do not write:

# 9.11 Flashing / Roof Intersection

- counterflashing;
- apron;
- cricket where applicable;
- sealant;
- corrosion;
- open joints;
- roof replacement errors;
- staining/leak path.

### Classification

Water intrusion can:
- damage masonry;
- accelerate freeze-thaw;
- damage liner/support;
- create interior deterioration.

But a flashing defect is not automatically the same as an immediate combustion safety failure.

# 9.12 Chimney Height / Termination

For current typical Part 9 masonry chimney rules in both province layers, verify where applicable:

- 900 mm above highest roof-contact point;
- 600 mm above highest roof surface/structure within 3 m horizontally.

### Historical warning

For old construction, confirm applicable historical code before making a retroactive legal conclusion.

- closure;
- corrosion;
- deposits;

The code can contain configuration-specific exceptions.

Do not create a generic “every fireplace chimney must have cleanout” statement.

# CROSS-SYSTEM INSPECTION RULES

# 13. Identification Rule

No appliance-specific compliance conclusion without enough appliance identity to determine the applicable requirement.

If model unknown:
**MANUFACTURER LOOKUP REQUIRED**

If no defensible requirement can be established:
**NOT VERIFIED**

---

# 14. Measurement Rule

Every measurement should answer a technical question.

Bad:
> Measure everything because the form has a field.

Good:
> Measure the controlling clearance required by the applicable source.

Each material measurement should record:

```text
Item:
Measured:
Required:
Source:
Method / reference point:
Photo:
Status:
```

---

# 15. Photo Rule

A photograph should prove one of:

- identity;
- measurement;
- configuration;
- condition;
- deficiency;
- limitation.

Avoid dozens of duplicate photos with no inspection value.

Do not delete the context photo and keep only a close-up.

Preferred:
1. context;
2. close-up;
3. measurement.

---

# 16. UTI Rule

Use UTI when:

- relevant item exists;
- inspection level does not permit access;
- access is unsafe;
- component is concealed;
- required identity/data cannot be observed;
- condition cannot be determined from available evidence.

UTI is not a failure.

UTI means:
**No compliance conclusion is made for that item.**

---

# 17. Not Applicable Rule

Use N/A only when the item genuinely does not apply.

Examples:
- no mantel → mantel-clearance field may be N/A.
- masonry fireplace → factory-built attic shield field is N/A.

Do not use N/A merely because the inspector did not inspect it.

---

# 18. Not Compliant Rule

A Not Compliant finding should contain:

1. observation;
2. measurement/evidence where relevant;
3. governing source;
4. technical significance;
5. recommended action.

Do not issue Not Compliant solely from:
- preference;
- “I usually do it this way”;
- another province’s rule;
- another manufacturer’s manual.

---

# 19. Compliant Rule

Compliant means the item inspected within the available scope meets the applicable requirement being evaluated.

It does not mean:

- the entire home is safe;
- every concealed component is acceptable;
- WETT has certified the appliance;
- future condition is guaranteed.

---

# 20. Permit Rule

Permit information can help establish:

- installation date;
- approved design;
- appliance identity;
- municipal inspection history.

But:

**Permit ≠ current WETT compliance**

A permitted installation can later be:
- altered;
- damaged;
- improperly repaired;
- obstructed;
- deteriorated.

Likewise:
**WETT report ≠ municipal permit closure**

---

# 21. Historical Installation Rule

If the system predates the current code:

Do not automatically apply current new-construction clauses retroactively.

Separate:

1. current observed condition;
2. current Fire Code maintenance/safety duty;
3. current alteration;
4. historical installation rule;
5. manufacturer/listing.

If historical compliance materially affects the outcome:

**CASE-SPECIFIC HISTORICAL CODE LOOKUP REQUIRED**

---

# 22. Manufacturer Rule

Manufacturer manual takes priority for appliance/system-specific items where the listing depends on it.

Common manufacturer-dependent items:

- appliance clearances;
- hearth R-value;
- chimney type;
- liner size;
- alcove use;
- mobile-home use;
- mantel/facing clearances;
- factory-built chimney components;
- supports;
- offsets;
- termination;
- insert/fireplace compatibility.

---

# 23. Chimney Fire Rule

If client reports or evidence suggests chimney fire:

- record history;
- photograph evidence;
- Fire Code post-fire inspection duty may apply;
- do not assume liner/chimney is intact;
- recommend Technical/Invasive evaluation where appropriate;
- specialist/video inspection may be required.

---

# 24. Creosote / Deposit Rule

Record:

- location;
- amount/appearance if observable;
- access limitation;
- sweep history.

Do not create a universal “annual sweep” law.

Ontario and Alberta current fire-code layers use:
- periodic dangerous-condition inspection;
- cleaning as often as necessary to prevent combustible deposit accumulation.

---

# 25. Water Damage Rule

Water damage can affect:

- masonry;
- liner;
- supports;
- factory-built chimney;
- framing;
- chase;
- roof interface.

Classify the actual issue:

- code construction;
- maintenance;
- property standard;
- structural;
- manufacturer;
- best practice.

Do not treat every leak as the same type of WETT deficiency.

> The [component] was inspected within the [Visual/Technical/Invasive] scope. The observed configuration and measured condition met the applicable [code/manufacturer/standard] requirement reviewed for this item.

---

## Not Compliant — Clearance

> The measured clearance between [component] and [combustible material] was approximately [measurement]. The applicable [manufacturer/code/standard] requirement is [requirement/reference]. The observed clearance does not meet that requirement. Correction is recommended before continued use.

---

## UTI — Concealed

> **Unable to Inspect (UTI):** The [component/clearance] is concealed and could not be evaluated within the agreed SITE® inspection level. No compliance conclusion is made for this item.

---

## Manufacturer Lookup

> The model/system-specific requirement could not be verified from the documentation available at the inspection. **MANUFACTURER LOOKUP REQUIRED** before a compliance conclusion is made.

---

## Historical Code

> The installation appears to predate the current code edition. Current observed safety/maintenance conditions are documented in this report. Original installation-code compliance requires confirmation of the installation/alteration date and the code edition in force at that time.

---

## Escalation

> Conditions observed during this inspection require evaluation beyond the present inspection scope. A higher SITE® inspection level and/or specialist evaluation is recommended before a final conclusion is made regarding the affected area.

# Exceptions / Edge Cases

# 30. Appliance Looks New but Label Is Missing

Age/appearance does not substitute for identification.

**MANUFACTURER LOOKUP REQUIRED**

---

# 31. Customer Has Manufacturer Manual for Similar Model

Do not use it unless the actual model matches.

---

# 32. Homeowner Says “The City Passed It Years Ago”

Record permit/inspection history if available.

Inspect the present condition independently.

---

# 33. Inspector Cannot Access Roof

At Visual level this may be within the agreed limitation.

Record:
- roof not accessed;
- observations from ground;
- relevant termination/crown items UTI if not reliably assessable.

Do not imply roof-level components were inspected.

---

# 34. Attic Hatch Exists but Access Is Unsafe

Unsafe access is not required merely because the hatch exists.

Record:
**UTI — access unsafe at time of inspection**

---

# 35. Insert Surround Hides Connection

Visual:
- UTI if connection not visible.

Technical:
- removal may be within scope if accessible and appropriate.

---

# 36. Factory-Built Chimney Is Enclosed in Finished Chase

Visual:
- external system only;
- concealed clearances/firestops often UTI.

Technical:
- inspect accessible attic/openings.

Invasive:
- opening chase if necessary and agreed.

---

# 37. Masonry Chimney Looks Good Outside

Exterior appearance does not prove:
- liner integrity;
- internal clearances;
- smoke chamber;
- hidden fire damage.

Use UTI where appropriate.

---

# 38. Crown Is Cracked but No Leak Is Visible

Record:
- actual crack;
- crown geometry;
- drainage;
- drip;
- water evidence.

Do not invent:
- active leak;
- structural failure;
- overall WETT failure.

---

# 39. Customer Wants “Just a Certificate”

Use correct terminology:
**WETT inspection report**

WETT certifies individuals, not the installation.

---

# 40. No Deficiencies Seen

Do not omit UTI.

A clean-looking Visual inspection can still contain legitimate inaccessible areas.
