JURISDICTION: CANADA — MANUFACTURER / LISTING LAYER  
LAST VERIFIED: 2026-09-22  
PURPOSE: Provide a controlled manufacturer-document lookup system for common solid-fuel appliances encountered by Apollo and Phoenix so inspectors can identify the exact model, retrieve the correct manufacturer manual, verify certification/listing, clearances, hearth/floor protection, chimney/liner requirements, and model-specific installation rules without inventing or generalizing requirements.

> **Critical rule:** Manufacturer requirements are appliance/system specific. A value or installation method verified for one model must never be generalized to another model, even within the same brand.

> **Critical revision rule:** Correct brand + correct model is not enough. Where manuals vary by serial range, revision, production date, suffix, or certification label, the exact applicable document must be matched to the inspected appliance.

> **Province rule:** The manufacturer layer does not replace the Ontario or Alberta legal layer. Use the manufacturer document together with the province-specific code/standard framework.

# Manufacturer Evidence Hierarchy

Use manufacturer evidence in this order:

1. **Certification/data label physically attached to the appliance**
2. **Exact official manufacturer manual applicable to model/serial**
3. **Official manufacturer model page**
4. **Official archived manufacturer manual**
5. **Official manufacturer technical bulletin / accessory instruction**
6. **Manufacturer technical support confirmation**
7. **Permit/installation record that identifies the exact product**
8. **Recognized certification/testing documentation**

Do not use:
- retailer summaries;
- marketplace listings;
- forum posts;
- generic product photos;
- another model's manual;
- AI-generated specifications

as the controlling source for a compliance conclusion.

# Label vs Website Rule

Some manufacturers expressly state that the certification label on the appliance controls if a discrepancy exists between the appliance label and other published material.

For this program:

## If label and manual agree
Use both.

## If label and official web page disagree
Use the label and investigate the applicable manual revision.

## If label and manual revision disagree
**SOURCE CONFLICT — MANUFACTURER REVIEW REQUIRED**

## If label is missing
Do not select a model only by appearance.

**MANUFACTURER LOOKUP REQUIRED**

# Serial / Revision Control

Before relying on a manual, record:

```text
Brand:

Model suffix:
Serial:
Manufacturing date:
Certification label:

Manual part/document number:
Manual revision:
Effective/revision date:

```

## Why this matters

Manufacturer document systems demonstrate that manuals can change by:

- serial range;
- production revision;
- product suffix;
- certification change;
- effective date.

Examples verified during this Phase:

- Regency publishes manual part number, revision and effective date.
- Drolet's manual/parts system separates products by serial range.
- Osburn's manual system separates current/inactive models and serial ranges.
- Enviro maintains current vs archived manual date ranges.
- Pacific Energy provides current and archived manuals by model/series.

Therefore:

**Model name alone is not sufficient evidence when a revision/serial distinction exists.**

# Manufacturer Lookup Workflow — Field Use

# Step 1 — Photograph Label

Required evidence where available:

- full label;
- model;
- serial;
- certification standard;
- manufacturing date;
- manufacturer name.

If the label is in a difficult location:
capture enough photos to make it legible.

---

# Step 2 — Normalize Model Name

Record the model exactly.

Examples:

Good:
- `F2500-1`
- `OB02015`
- `F 500 V3`
- `Encore 2040`
- `Explorer III`

Bad:
- `Regency medium stove`
- `Osburn 2000-ish`
- `Jotul Oslo`
- `black wood stove`

Suffixes matter.

---

# Step 3 — Match Manual

Confirm:

- model;
- revision;
- serial range;
- effective date.

If manufacturer portal returns multiple manuals:

**DO NOT PICK THE NEWEST AUTOMATICALLY.**

Pick the one applicable to the inspected appliance.

---

# Step 4 — Record Certification

Store:

```text
Certification Standard:
Testing / Listing Organization:
Report Number:
Label Photo:
```

Do not infer province-code compliance solely because the product is listed.

Product certification and installation compliance are separate questions.

---

# Step 5 — Extract Only Inspection-Critical Requirements

Do not copy entire manuals.

Extract:

- appliance clearance;
- connector clearance/configuration;
- hearth/floor protection;
- thermal R-value where required;
- chimney type;
- chimney diameter;
- liner requirement;
- minimum chimney height where manufacturer states one;
- mantel/facing clearances;
- mobile-home rule;
- alcove rule;
- outside-air rule;
- approved components;
- termination;
- special labels/warnings;
- fireplace-modification restrictions.

---

# Step 6 — Match Province

Manufacturer requirement is one layer.

Ontario:
use Ontario legal/standard layer.

Alberta:
use Alberta legal/standard layer.

If manufacturer requirement and province requirement appear inconsistent:

**SOURCE CONFLICT — HUMAN REVIEW REQUIRED**

Do not choose the more convenient value.

---

Recommended inspection record:

```text
Manual revision:
Source URL:

Requirement used:

```

**MANUFACTURER LOOKUP REQUIRED**

**Not Compliant**

# Missing Manual Rule

If official manual cannot be found:

1. verify label.
2. search manufacturer archived manuals.
3. search manufacturer support/technical portal.
4. contact manufacturer/dealer technical support.
5. search certification/testing documentation.
6. check permit/installation records.

If still unresolved:

**NOT VERIFIED**

Do not replace the missing manual with:
- another model;
- generic installation guide;
- retailer page.

# Discontinued Appliance Rule

Discontinued does not mean unusable for inspection.

For discontinued appliances:

- use official archived documentation;
- match serial/revision;
- preserve original certification/listing;
- evaluate against applicable historic/current jurisdiction framework.

Do not force a discontinued appliance into the current replacement model's manual.

For every manufacturer-based Not Compliant finding retain:

1. appliance label photo;

# Reporting Guidance

## Manufacturer Clearance Deficiency

> The appliance was identified as [brand/model/serial]. The applicable manufacturer manual [document/revision] specifies [requirement] for the observed installation configuration. The measured condition was approximately [measurement], which does not meet the verified manufacturer requirement.

---

## Manual Not Available

> The appliance was identified as [brand/model if known]; however, the applicable manufacturer installation documentation could not be confirmed for the inspected serial/revision. Model-specific clearance/venting requirements are therefore **NOT VERIFIED** pending manufacturer documentation.

---

## Label Missing

> The appliance certification/data label could not be located or read. Because the label is needed to confirm the exact model/listing and applicable manufacturer requirements, model-specific compliance could not be fully established. **MANUFACTURER LOOKUP REQUIRED.**

---

## Wrong / Mixed Chimney Components

> The observed chimney components could not be confirmed as part of the fireplace/chimney manufacturer's listed system. Component compatibility requires verification against the exact manufacturer system documentation before the installation can be represented as compliant.

---

## Historic Manual

> The appliance is an older/discontinued model. The inspection uses archived manufacturer documentation applicable to the identified model/serial rather than the current replacement product documentation.

# Exceptions / Edge Cases

# 1. Same Model Name, Different Generation

Example:
- Jøtul F 500 vs F 500 V3.
- Quadra-Fire 5700 ACT vs ACC vs ACC-C.

Treat them as different appliances until documentation proves otherwise.

---

# 2. Manual Download Has No Visible Revision

Record:
- document ID;
- download URL;
- date accessed;
- label/serial.

Do not invent a revision.

---

# 3. Web Product Page and Label Differ

Label controls for appliance-specific tested data where manufacturer identifies that hierarchy.

Investigate the correct manual.

---

# 4. Manufacturer Is Out of Business

Use:
- archived official manuals;
- certification lab;
- AHJ records;
- permit documentation.

If not defensible:
**NOT VERIFIED**

---

# 5. Customer Supplies a Printed Manual

Verify:
- exact model;
- revision;
- serial applicability.

A manual physically stored beside the stove is not proof that it belongs to that stove.

---

# 6. QR Code on Appliance

Use it as a search aid.

Still verify:
- model;
- serial;
- source domain;
- revision.

---

# 7. Manufacturer Manual Uses U.S. and Canadian Values

Use the **Canadian** values for Apollo/Phoenix.

Do not copy U.S. hearth/clearance values into Canadian inspections.

---

# 8. Manufacturer Manual Refers to an Older Canadian Standard

Do not assume the appliance became invalid.

Product certification edition and provincial installation-code edition are separate questions.

Record both accurately.
