# Executive Summary

Ontario’s current Building Code is established through **O. Reg. 163/24**, which adopts the **National Building Code of Canada 2020, First Printing**, with Ontario amendments. The current Ontario Amendment Document identified by the regulation is dated **July 17, 2026**.

For the solid-fuel inspection topics relevant to Apollo, the current Ontario Amendment Document references:

- **CSA B365-17** — Installation code for solid-fuel-burning appliances and equipment.
- **CAN/ULC-S610:2018** — Factory-Built Fireplace Systems.
- **ULC-S628-2022** — Fireplace Inserts and Hearth-Mounted Stoves.
- **CAN/ULC-S629:2022** — 650°C Factory-Built Chimneys.
- **CAN/ULC-S639:2018** — Steel Liner Assemblies for Solid Fuel-Burning Masonry Fireplaces.

This is one of the most important conclusions in the entire Ontario program:

**CSA B365:25 is the newest CSA edition, but Ontario currently references B365-17.**

The Ontario Building Code provides the principal construction/installation rules for chimneys, fireplaces, liners, hearths, clearances, and related building work.

The Ontario Fire Code independently creates ongoing duties for existing systems. Its current provisions require chimneys, flues, and flue pipes to be inspected for dangerous conditions at intervals not exceeding 12 months, when an appliance is added, and after a chimney fire. They must also be cleaned as often as necessary to remain free of combustible deposits. The Fire Code expressly applies these Section 2.6 service-equipment provisions to individual dwelling units.

The current Ontario Fire Code also references **CSA B365-17** for installation and maintenance of solid-fuel-burning appliances and equipment.

Ottawa adds important administrative and property-maintenance requirements:

- A City of Ottawa building permit is required for listed fireplace/wood-burning projects including masonry fireplaces/chimneys, woodstoves/chimneys, pellet stoves, fireplace inserts/chimney liners, and pre-manufactured fireplaces/chimneys.
- Ottawa Property Standards requires chimneys and related equipment to be maintained safely and free of defects that can permit smoke/gases into a dwelling.
- Ottawa Fire Services publishes chimney and wood-burning safety guidance.
- Heritage approval may be separately required where work affects protected heritage attributes.
- Exterior projections can also engage zoning requirements.

Ottawa does **not** replace the Ontario technical code with a separate general “Ottawa fireplace code.”

# 3. Existing Building / Existing Installation Principle

The current Ontario Amendment Document includes provisions addressing work on existing buildings. In general, where an existing building is extended, materially altered, or repaired, the Code applies to the extension and the portions materially altered or repaired, subject to specific existing-building provisions.

### Critical WETT implication

A WETT inspector must not mechanically apply every 2026 construction provision retroactively to an untouched historic installation and call the difference a current-code violation.

For older systems establish, where materially relevant:

- approximate installation date;
- permit history if available;
- alteration/relining/replacement date;
- manufacturer/listing;
- dangerous current condition;
- Fire Code ongoing duties;
- whether current work triggered current Building Code requirements.

### Limitation

The precise legal treatment of an old installation can depend on the facts, previous code edition, permit history, and enforcement authority.

# 21. Ontario-Specific Outdoor Combustion Air for Fireplaces

**Primary Ontario Amendment:** 9.22.1.4

This is an important Ontario-specific provision.

Current Ontario amendments require **every solid-fuel-fired fireplace, including a factory-built fireplace**, to have a means of supplying outdoor combustion air.

The current Ontario provision specifies key design elements, including:

- duct constructed of noncombustible, corrosion-resistant material;
- outside termination;
- minimum duct size equivalent to **100 mm diameter**;
- a tight-fitting damper near the interior outlet;
- damper operation from the room containing the fireplace;
- indication of damper position;
- interior outlet located close to the fireplace opening and arranged to prevent embers entering the duct.

### Inspector checks

- outdoor air provision present.
- duct material.
- approximate diameter.
- outside termination.
- damper.
- control.
- outlet position.
- blockage/disconnection.

### Applicability warning

# 30. Chimney / Flue / Flue-Pipe Inspection Frequency

**Primary Reference:** Ontario Fire Code 2.6.1.4

Every chimney, flue, and flue pipe must be inspected to identify any dangerous condition:

# 32. Cleaning / Combustible Deposits / Creosote

**Primary Reference:** Ontario Fire Code 2.6.1.5

Chimneys, flues, and flue pipes must be cleaned as often as necessary to keep them free from combustible deposits.

### Critical business/reporting rule

Do **not** tell customers:

> “Ontario law requires every chimney to be swept once per year.”

That is not what this provision says.

The Fire Code requires:

- inspection at intervals not exceeding 12 months;
- cleaning **as often as necessary** to prevent combustible deposits.

Creosote accumulation is a common combustible deposit, but sweep frequency depends on condition/use.

# 7. Cracked Crown Example

The report classification should be based on the actual measured/observed condition and applicable code provision rather than the word “crack” alone.

---

## 7. Chimney has not been swept in one year

Do not automatically call this a Fire Code violation based only on time.

The Fire Code requires:
- inspection within 12 months;
- cleaning as often as necessary to control combustible deposits.

Actual deposit condition matters.

---

## 8. Chimney fire occurred

Ontario Fire Code requires inspection after a chimney fire.

A higher WETT inspection level may be appropriate depending on damage/access.

---

## 9. Insert installed without full liner

Do not make a conclusion from the phrase “no full liner” alone.

Current Ontario 9.22.10.2 provides specific permitted installation paths, including listed liner and certain direct sealed connections when part of a conforming insert system.

Verify:
- insert listing.
- installation manual.
- original fireplace/chimney.
- exact connection method.

---

## 10. Heritage home

Heritage status does not waive fire/building requirements.

It may add a separate approval process before exterior alteration.
